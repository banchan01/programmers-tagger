# Programmers Tagger

프로그래머스 코딩테스트 연습 문제(689개)에 알고리즘 유형 태그를 붙여 보여주는 크롬 확장 프로그램입니다.

- 문제 목록과 문제 풀이 화면의 제목 옆에 유형 태그(DP, DFS/BFS, 그리디, SQL 등)를 표시합니다.
- 문제 목록 위의 "유형으로 찾기"에서 유형과 난이도를 골라 전체 문제 중 해당하는 문제만 모아 볼 수 있습니다.
- 확장 아이콘의 "유형 가리기"를 켜면 태그가 흐리게 가려지고, 마우스를 올려야 보입니다.

유형은 문제 본문을 읽고 한 번 분류해 `labels.json`에 저장해 두었고, 확장 프로그램은 이 파일만 읽어서 표시합니다. AI로 분류했기 때문에 일부 태그는 틀릴 수 있습니다.

## 설치

1. 이 저장소를 내려받습니다.
2. 크롬 주소창에 `chrome://extensions`를 입력하고 오른쪽 위의 "개발자 모드"를 켭니다.
3. "압축해제된 확장 프로그램을 로드합니다"를 누르고 이 폴더를 선택합니다.
